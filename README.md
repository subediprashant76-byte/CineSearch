# CineSearch

Browse and search movies using the TMDB API. Built with React.

## Features

- Search with a debounced input
- Filter by genre
- Pagination
- Movie detail page with React Router
- Loading skeletons and error messages

## Setup

You need a free API key from https://www.themoviedb.org/settings/api

```
npm install
cp .env.example .env
```

Put your key in `.env`, then:

```
npm run dev
```
